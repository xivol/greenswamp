### Серверное программирование
**Платформа:** [edu.mmcs.sfedu.ru](https://edu.mmcs.sfedu.ru/course/view.php?id=555)
**Всего лекций:** 18

---

### Модуль 1. Клиент-серверное взаимодействие

**Лекция 1. Сети и модель OSI**
- **Описание:** Введение в принципы компьютерных сетей. Изучение семиуровневой модели OSI, принципов маршрутизации и передачи данных.
- **Ключевые темы:** Модель OSI (уровни 1–7), стек TCP/IP, IP-адресация, порты, система доменных имен (DNS), сниффинг трафика (Wireshark).

**Лекция 2. Протокол HTTP/S**
- **Описание:** Глубокое погружение в протокол HTTP — основу веб-коммуникации. Разбор методов, статус-кодов, заголовков и цикла «запрос-ответ». Введение в HTTPS и шифрование. Работа с HTTPListener.
- **Ключевые темы:** HTTP-методы (GET, POST, PUT, DELETE), статус-коды, заголовки, цикл Request/Response, HTTPS, TLS/SSL. System.Net, HTTPListener.

**Лекция 3. Асинхронность с C#, различные подходы к асинхронности**
- **Описание:** Изучение класса Task, ключевых слов async/await, отличие асинхронности и многопоточности в C#. Механизмы ConfigureAwait, отмена операций через CancellationToken. Паттерны параллельного выполнения (WhenAll, WhenAny), асинхронные потоки IAsyncEnumerable, работа с коллекциями System.Collections.Concurrent. Асинхронная работа с HTTPListener.
- **Ключевые темы:** System.Threading, Task, async/await, ConfigureAwait, CancellationToken, Task.WhenAll/WhenAny, IAsyncEnumerable, ConcurrentDictionary.

---

### Модуль 2. Ядро серверного приложения на ASP.NET Core

**Лекция 4. Конвейер обработки запросов в ASP.NET Core**
- **Описание:** Обзор архитектуры ASP.NET Core: хост, сервер, конвейер middleware. Как запрос проходит через цепочку компонентов. Написание собственного middleware. Базовое знакомство с Dependency Injection (DI).
- **Ключевые темы:** Архитектура ASP.NET Core, Middleware, Request Delegates, Use/Run/Map, HttpContext, основы Dependency Injection.

**Лекция 5. Dependency Injection, сервисы и конкурентность**
- **Описание:** Углубленное изучение DI как инструмента для создания тестируемых приложений. Регистрация сервисов, времена жизни (Singleton, Scoped, Transient). Внедрение через конструктор. Рассматриваются вопросы конкурентности — поведение сервисов при параллельных запросах и базовые стратегии борьбы с состояниями гонки (race conditions).
- **Ключевые темы:** IServiceCollection, ServiceLifetime, потокобезопасность, Scoped-сервисы, утечки памяти, Lock, SemaphoreSlim.

**Лекция 6. Построение REST API с ASP.NET Core**
- **Описание:** Создание API-контроллеров, атрибутная маршрутизация, возврат данных в JSON. Документирование через Swagger/OpenAPI и тестирование в Postman. Принципы REST: ресурсы, глаголы, коды состояний. Контент-негосиация.
- **Ключевые темы:** [ApiController], [Route], IActionResult, FromBody, FromRoute, Swagger/OpenAPI, Postman, content negotiation.

### Модуль 3. Работа с данными — реляционные базы, SQL, NoSQL и аналитика

**Лекция 7. Entity Framework Core (EF Core)**
- **Описание:** Введение в объектно-реляционное отображение (ORM). Подход Code First, роль DbContext, маппинг классов на таблицы БД. Настройка через Data Annotations и Fluent API. Создание сервиса фоновой задачи (BackgroundService) для автоматического наполнения БД тестовыми данными при запуске приложения с использованием библиотеки Faker.Net.
- **Ключевые темы:** ORM, DbContext, DbSet, Code First, Fluent API, Data Annotations, миграции.

**Лекция 8. SQL для backend-разработчика: индексы, запросы, производительность**
- **Описание:** Глубокое понимание того, что происходит под капотом EF Core. Логирование генерируемого SQL. Написание сырых запросов через FromSqlRaw и Dapper. Типы индексов, планы выполнения (EXPLAIN), проблема N+1 и её решение (Include, AsSplitQuery). Профилирование базы данных приложения социальной сети.
- **Ключевые темы:** SqlConnection, Dapper, индексы (B-tree, GiST), AsNoTracking, планы запросов, денормализация.

**Лекция 9. NoSQL, ClickHouse и векторные базы данных: как, когда и зачем**
- **Описание:** Современные приложения часто требуют разных моделей хранения данных. Обзор нереляционных хранилищ и их место в экосистеме backend-разработки. Выбор инструмента под задачу и подключение из .NET. Практические сценарии в социальной сети.
- **Ключевые темы:**
  - Key-Value (Redis): кеширование, счётчики, сессии.
  - Document (MongoDB): гибкая схема, JSON-документы, профили пользователей.
  - Column-family (ClickHouse): аналитический движок, колоночное хранение, обработка событий и агрегации в реальном времени, ClickHouse.Client.
  - Векторные базы данных (pgvector, Qdrant): эмбеддинги, семантический поиск, рекомендации, RAG-системы, поиск ближайших соседей (kNN).
  - CAP-теорема, полиглотное персистанс, правила выбора между SQL и NoSQL.

### Модуль 4. Backend-For-Frontend с Razor Pages

**Лекция 10. Razor Pages как слой представления**
- **Описание:** Использование готовых HTML-шаблонов для построения UI. Синтаксис Razor, макеты, секции. PageModel как логика страницы, работающая исключительно через вызовы внутреннего REST API (созданного в Лекции 6). Демонстрация разделения backend и frontend внутри одного проекта.
- **Ключевые темы:** Синтаксис Razor (символ @, блоки кода), макеты (_Layout.cshtml), секции, PageModel, обработчики (OnGet, OnPost), привязка моделей, внедрение IHttpClientFactory для вызова API.

---

### Модуль 5. Аутентификация и безопасность

**Лекция 11. Cookie-аутентификация с ASP.NET Core Identity**
- **Описание:** Знакомство с моделями IAAA (Identity, Access, Authentication, Authorization). Реализация регистрации, входа, ролей, утверждений (claims) и политик доступа. Защита Razor Pages и API-контроллеров с помощью cookie-авторизации.
- **Ключевые темы:** Модель IAAA, ASP.NET Core Identity, UserManager, SignInManager, [Authorize], роли, claims, политики.

**Лекция 12. Токен-аутентификация для API (JWT)**
- **Описание:** Почему куки неудобны для мобильных и SPA-клиентов. Выдача JWT-токенов через конечную точку Identity. Валидация токенов на API-контроллерах. Refresh-токены. Базовая настройка OAuth 2.0 / OpenID Connect.
- **Ключевые темы:** JwtSecurityTokenHandler, JwtBearerDefaults, AddAuthentication().AddJwtBearer(), claims, срок действия токенов, безопасное хранение секретов.

### Модуль 6. Продвинутые API-технологии

**Лекция 13. GraphQL с Hot Chocolate**
- **Описание:** Графовый язык запросов как альтернатива REST. Решение проблем over-fetching и under-fetching. Построение схемы (Schema), реализация Query, Mutation и Subscription. Интеграция с EF Core через DataLoader.
- **Ключевые темы:** GraphQL, Schema First / Code First, Query, Mutation, Subscription, Hot Chocolate, DataLoader, пагинация.

**Лекция 14. gRPC и Protocol Buffers**
- **Описание:** Высокопроизводительная альтернатива REST на основе HTTP/2. Описание контрактов в .proto, кодогенерация. Унарный, серверный, клиентский и двунаправленный стриминг. Сравнение с REST и GraphQL.
- **Ключевые темы:** Protocol Buffers, protobuf, gRPC-клиент, стриминг, Grpc.Net.Client, Channel.

---

### Модуль 7. Реальное время, надёжность и наблюдаемость

**Лекция 15. Реальное время с SignalR**
- **Описание:** Механизмы обратной связи с клиентом. Введение в WebSockets и библиотеку SignalR для создания интерактивных приложений. Создание хабов (Hubs), отправка уведомлений клиентам, управление группами. Применение в соцсети (лайки, сообщения).
- **Ключевые темы:** WebSockets, SignalR Hub, Clients.All, Groups, ConnectionId, транспортные протоколы.

**Лекция 16. Кеширование, фоновая обработка и отказоустойчивость**
- **Описание:** Снижение нагрузки с помощью IMemoryCache и распределённого кеша (Redis). Простейшая очередь сообщений через System.Threading.Channels. Паттерны Retry и Circuit Breaker с Polly. Логирование (Serilog) и Health Checks для мониторинга приложения в продакшене.
- **Ключевые темы:** IMemoryCache, IDistributedCache, StackExchange.Redis, Channel<T>, BackgroundService, ILogger<T>, UseHealthChecks, Polly.

---

### Модуль 8. Тестирование и развёртывание

**Лекция 17. Автоматизированное тестирование backend-приложений**
- **Описание:** Знакомство с «Пирамидой тестирования». Модульные тесты (xUnit, Moq). Интеграционные тесты с WebApplicationFactory. Тестирование API, базы данных и аутентификации. Организация тестовых проектов в решении.
- **Ключевые темы:** Пирамида тестирования, модульное тестирование, интеграционное тестирование, xUnit, Moq, WebApplicationFactory, Testcontainers.

**Лекция 18. CI/CD и контейнеризация с Docker**
- **Описание:** Основы Docker (образы, контейнеры, Dockerfile). Сборка образа приложения и настройка пайплайна для автоматического билда, тестирования и деплоя. Стратегии развёртывания.
- **Ключевые темы:** Docker, контейнеры, образы, Dockerfile (multistage), docker-compose, CI/CD-пайплайны, реестры контейнеров, переменные окружения, HTTPS в контейнере.
