### Серверное программирование
**Платформа:** [edu.mmcs.sfedu.ru](https://https://edu.mmcs.sfedu.ru/course/view.php?id=555)
**Всего лекций:** 16

### Модуль 1. Клиент-серверное взаимодействие

**Лекция 1. Сети и модель OSI**
- **Описание:** Введение в принципы компьютерных сетей. Изучение семиуровневой модели OSI, принципов маршрутизации и передачи данных.
- **Ключевые темы:** Модель OSI (уровни 1–7), стек TCP/IP, IP-адресация, порты, система доменных имен (DNS).

**Лекция 2. Протокол HTTP/S, асинхронная обработка запросов**
- **Описание:** Глубокое погружение в протокол HTTP — основу веб-коммуникации. Разбор методов, статус-кодов, заголовков и цикла «запрос-ответ». Введение в HTTPS и шифрование. Асинхронность с C#, различные подходы к асинхронности.
- **Ключевые темы:** HTTP-методы (GET, POST, PUT, DELETE), статус-коды, заголовки, цикл Request/Response, HTTPS, TLS/SSL. System.Threading, async, await, yield.

**Лекция 3. Конвейер обработки запросов в ASP.NET Core**
- **Описание:** Обзор архитектуры ASP.NET Core и того, как запрос проходит через middleware-компоненты. Базовое знакомство с Dependency Injection (DI).
- **Ключевые темы:** Архитектура ASP.NET Core, Middleware, Request Delegates, основы Dependency Injection.

### Модуль 2. Веб-приложения. Разработка пользовательского интерфейса

**Лекция 4. Синтаксис Razor и макеты**
- **Описание:** Практическое освоение Razor-синтаксиса для встраивания C#-кода в HTML. Создание единого макета сайта с общими элементами (шапка, подвал, навигация).
- **Ключевые темы:** Синтаксис Razor (символ `@`, блоки кода, выражения), макеты (`_Layout.cshtml`), секции, ViewStart.

**Лекция 5. Конвейер Razor Pages**
- **Описание:** Знакомство с архитектурой Razor Pages, маршрутизацией и жизненным циклом обработки запроса от URL до готовой HTML-страницы.
- **Ключевые темы:** Архитектура Razor Pages, маршрутизация, обнаружение страниц, жизненный цикл запроса.

**Лекция 6. PageModel и обработчики**
- **Описание:** Изучение класса `PageModel`, который отделяет логику от представления. Настройка методов-обработчиков (`OnGet`, `OnPost`) для реакции на разные HTTP-глаголы и привязка данных из запроса.
- **Ключевые темы:** Класс PageModel, методы-обработчики (`OnGet`, `OnPost` и др.), привязка моделей (Model Binding).

**Лекция 7. Dependency Injection, сервисы и конкурентность**
- **Описание:** Углубленное изучение DI как инструмента для создания тестируемых приложений. Регистрация сервисов, времена жизни (Singleton, Scoped, Transient).
- **Важно:** Рассматриваются вопросы конкурентности — поведение сервисов при параллельных запросах и базовые стратегии борьбы с состояниями гонки (race conditions).
- **Ключевые темы:** Dependency Injection, времена жизни сервисов, конкурентность и потокобезопасность, Scoped-сервисы, внедрение через конструктор.

### Модуль 3. Разработка веб-сервисов, работа с данными, аутентификация и API

**Лекция 8. Entity Framework Core (EF Core)**
- **Описание:** Введение в объектно-реляционное отображение (ORM). Подходы Code First и Database First, роль `DbContext`, маппинг классов на таблицы БД. Настройка через Data Annotations и Fluent API. Создание сервиса фоновой задачи (`BackgroundService`) для автоматического наполнения БД тестовыми данными при запуске приложения с использованием библиотеки `Faker.Net`.
- **Ключевые темы:** ORM, DbContext, DbSet, Code First, Fluent API, Data Annotations, миграции.
  
**Лекция 9. Аутентификация и авторизация с ASP.NET Core Identity**
- **Описание:** Знакомство с моделями IAAA (Identity, Access, Authentication, Authorization). Реализация регистрации, входа, ролей, утверждений (claims) и политик доступа.
- **Ключевые темы:** Модель IAAA, ASP.NET Core Identity, UserManager, SignInManager, роли, claims, политики.

**Лекция 10. Миграция на ASP.NET Core Identity**
- **Описание:** Практическое занятие по интеграции Identity в существующую базу данных. Создание кастомных пользовательских таблиц и написание миграций без потери данных.
- **Ключевые темы:** Миграция базы данных, IdentityUser, кастомные профили пользователей, маппинг сущностей.

**Лекция 11. ASP.NET Core Web API и RESTful-сервисы**
- **Описание:** Переход от генерации HTML к созданию API. Изучение принципов REST, создание контроллеров, маршрутизация, возврат JSON-ответов и документирование через Swagger/OpenAPI.
- **Ключевые темы:** Принципы REST, ApiController, атрибутная маршрутизация, контент-негосиация (JSON), Swagger/OpenAPI, Postman.

**Лекция 12. GrapgQL и gRPC -- системный подход к разработке API**
- **Описание:** Введение в язык запросов GraphQL как альтернативу REST. Решение проблем over-fetching и under-fetching. Построение схемы (Schema), реализация Query, Mutation и Subscription с использованием Hot Chocolate. Освоение gRPC на основе HTTP/2 и Protocol Buffers (Protobuf). Генерация кода из .proto-контрактов. Стриминг данных между клиентом и сервером.
- **Ключевые темы:** GraphQL, Schema First / Code First, Query, Mutation, Subscription, Hot Chocolate, DataLoader. gRPC, Protocol Buffers, HTTP/2, кодогенерация, Unary / Server-стриминг / Client-стриминг / Bidirectional-стриминг, gRPC-клиенты.

### Модуль 4. Приложения в режиме реального времени, тестирование и развертывание приложений

**Цель модуля:** Освоить современные подходы к разработке: веб-сокеты для реального времени, автоматическое тестирование и контейнеризация для деплоя.

**Лекция 13. Реальное время с SignalR**
- **Описание:** Механизмы обратной связи с клиентом. Введение в WebSockets и библиотеку SignalR для создания интерактивных приложений. Создание хабов (Hubs), отправка уведомлений клиентам, управление группами.
- **Ключевые темы:** WebSockets, SignalR Hub, клиенты, широковещательные рассылки, управление группами, обработка подключений.

**Лекция 14. Тестирование в ASP.NET — Основы**
- **Описание:** Знакомство с «Пирамидой тестирования». Написание модульных (Unit) и интеграционных тестов с использованием xUnit, Moq и `WebApplicationFactory`.
- **Ключевые темы:** Пирамида тестирования, модульное тестирование, интеграционное тестирование, xUnit, Moq, WebApplicationFactory.

**Лекция 15. Тестирование, структура проекта и CI/CD**
- **Описание:** Как организовать решение для удобного тестирования (выделение проектов Unit, Integration, Functional). Введение в концепции непрерывной интеграции и доставки (CI/CD) и автоматический прогон тестов в пайплайне.
- **Ключевые темы:** Структура проекта, тестовые проекты, WebApplicationFactory, Continuous Integration (CI), Continuous Deployment (CD).

**Лекция 16. Деплой с Docker и CI/CD**
- **Описание:** Финальная лекция о современных стратегиях развертывания. Основы Docker (образы, контейнеры, Dockerfile). Сборка образа приложения и настройка пайплайна для автоматического билда и деплоя.
- **Ключевые темы:** Docker, контейнеры, образы, Dockerfile, CI/CD-пайплайны, реестры контейнеров.
